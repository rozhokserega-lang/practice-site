# Образ Андрея Соколова — учебная практика

Учебный сайт по литературе: образ Андрея Соколова (рассказ М. А. Шолохова «Судьба человека»).

## Что внутри

- Конспект материала
- Презентация
- Задания на LearningApps
- Тесты с проверкой ответов
- Галерея изображений с каруселью
- Видеоматериалы
- Кроссворд
- Разработки уроков

## Технически

Один самодостаточный файл `index.html` — все изображения вшиты в base64, внешних зависимостей нет.
Достаточно открыть файл в браузере, интернет не требуется.

Тёмная тема включается автоматически по настройкам системы, также есть переключатель вручную.
